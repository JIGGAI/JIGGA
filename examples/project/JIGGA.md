# JIGGA Project Instructions

## Project Purpose

This is an example JIGGA-enabled project.

## Common Commands

```bash
npm test
npm run lint
```

## Agent Rules

- Prefer small, reviewable changes.
- Do not edit secrets or environment files.
- Summarize changed files and test results before marking work done.

## Do Not Touch

- `.env`
- `secrets/`
- private credentials
