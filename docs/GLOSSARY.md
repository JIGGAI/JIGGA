# Glossary

## Agent

An AI worker with a role, model, memory scope, permissions, tools, and wake conditions.

## Supervisor

The always-on daemon that wakes agents and teams based on schedules, events, tasks, and agent requests.

## Team

A reusable group of agents configured to work together.

## Workflow

A reusable playbook or SOP that defines a sequence of actions for repeatable work.

## Task

A unit of work assigned to an agent or team.

## Memory Kernel

The system responsible for storing, indexing, summarizing, and retrieving persistent memory.

## Memory Scope

A named view of memory that controls what an agent can access.

## Policy

A set of permissions and restrictions governing an agent's capabilities.

## Wake Event

An event that causes the supervisor to run an agent or team.

## Workflow Inference

The process of detecting repeated behavior and proposing a reusable workflow.

## Plan

A preview of what JIGGA will create, modify, enable, or execute before applying changes.

## Apply

The action of approving and committing a planned change.
